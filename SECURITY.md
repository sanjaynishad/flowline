# Security Policy

## Reporting a vulnerability

Flowline is **local-first** — it stores data on your device and the browser bridge only listens on `localhost`. Still, if you find a security issue, we want to hear about it.

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, report it privately using GitHub's [private vulnerability reporting](https://github.com/sanjaynishad/flowline/security/advisories/new), or contact the maintainer via [sanjaynishad.com](https://www.sanjaynishad.com/).

When reporting, please include:

- A description of the vulnerability and its impact.
- Steps to reproduce (or a proof of concept).
- The Flowline version and your OS version.

We'll acknowledge your report as quickly as we can and keep you updated on the fix.

## Supported versions

Flowline is pre-1.0. Security fixes are applied to the latest release on `main`.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |
